Reading Unit 11: Subjunctive Mood

Thức giả định

1. Câu điều kiện loại 1 (First Conditional)

Công thức

If + S + V (hiện tại đơn), S + modal verb (will/can/should…) + V

Diễn tả điều kiện có thể xảy ra ở hiện tại/tương lai.

If it rains tomorrow, the retreat will be canceled.

2. Câu điều kiện loại 2 (Past Subjunctive)

Công thức

If + S + V-ed/were (quá khứ đơn), S + would/could/might + V (bare)

Diễn tả điều không có thật ở hiện tại (giả định trái với thực tế hiện tại).

If I had millions of US dollars now, I would give you a half.

Lưu ý

Với động từ to be, dùng were cho mọi ngôi (kể cả I/he/she/it): If I were you, I would continue…

3. Câu điều kiện loại 3 (Past Perfect Subjunctive)

Công thức

If + S + had + V-p2 (quá khứ hoàn thành), S + would have + V-p2

Diễn tả điều không có thật trong quá khứ (giả định trái với thực tế đã xảy ra).

If I had learned TOEIC earlier, I would have had a good job.

4. Câu điều kiện hỗn hợp (Mixed Subjunctive)

If clause Main clause
If + quá khứ hoàn thành (loại 3) S + would + be/V (bare) — kết quả ảnh hưởng đến hiện tại

The clients wouldn't be so confused now if the travel agency had posted the information.

5. Bảng tổng hợp 3 loại câu điều kiện

Loại Mệnh đề IF Mệnh đề chính
1 S + V (hiện tại đơn) S + will/can/should… + V
2 S + V-ed/were (quá khứ đơn) S + would/could/might + V
3 S + had + V-p2 (quá khứ hoàn thành) S + would have + V-p2
