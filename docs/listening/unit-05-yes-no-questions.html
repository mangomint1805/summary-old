Listening Unit 5: Part 2 – Yes/No Questions

Câu hỏi Yes/No

1. Câu hỏi với Be / trợ động từ (Questions with Be/Auxiliary Verb)

Dạng trả lời Ví dụ
Yes/No + Detail (có/không + chi tiết bổ sung) Is Mr. Ito in charge of customer service? → Yes, he is managing it.
Detail without Yes/No (trả lời thẳng chi tiết, không có Yes/No) Do you have a pen I can borrow? → I lent it to John.

2. Câu hỏi với động từ khiếm khuyết (Questions with Modal Verbs)

2.1. Request (Yêu cầu, đề nghị giúp đỡ) — Could/Can/Would you…?

Thay cho "Yes" Thay cho "No"
of course / sure / certainly /ˈsɜːtnli/ / no problem sorry / I'm sorry, but… / I'm afraid I can't / I'd be happy to, but…

Could you help Lisa organize the client files? → Sure, as soon as I finish this report. (Sure + chi tiết)

2.2. Suggestion (Đề nghị, gợi ý) — Should we…? / Would you care to…?

Thay cho "Yes" Thay cho "No"
that sounds like a good/great idea / sounds good to me / sure, that sounds exciting sorry / I'm sorry, but… / I'm afraid I can't / I'd be happy to, but…

Should we make a new company logo? → That sounds like a great idea.

4. Tổng hợp

Tình huống Cách trả lời
Câu hỏi Be/aux thông thường Yes/No + chi tiết, hoặc chi tiết trực tiếp (không Yes/No)
Request (Could/Can/Would you…?) Đồng ý: sure, of course, certainly, no problem (+ chi tiết) — Từ chối: sorry, I'm afraid I can't…
Suggestion (Should we…? / How about…?) Đồng ý: sounds good, that sounds like a good idea — Từ chối: sorry, I'd be happy to but…
